## Nexus Studios

We make resources for FiveM servers and build them like products: every outcome is decided on the server, every option is documented, and the interface is designed, not assembled.

### Open source

| | |
|---|---|
| **[Nexus UI](https://github.com/NexusStudiosCfx/nexus-ui)** | A UI framework for FiveM. Components in `.nexus` files that compile to direct DOM updates, one typed contract that validates every message on the server, and screens that cost nothing while they are closed. MIT. |

### What we build

| | |
|---|---|
| **Casino and games** | Casino, Lottery, Scratchers, Cards, Bookmaker, Poker, Table Games, Bingo, Arcade, Claw, Racing, Bar Games |
| **Economy** | Exchange, Crypto, Credit, Insurance, Auctions, Treasury, Pawn, Boss |
| **Live events** | Trivia, Tournaments, Pass, Car Meets |
| **City life** | Elections, Newsroom, Eats, Build, Forensics, EMS |

Most of them also come as an app for LB Phone and LB Tablet.

### How we build

- **The server decides.** Bets, payouts, prices and permissions never trust the client. The interface only shows what the server said.
- **Your framework, detected.** Qbox, QBCore and ESX, with ox_inventory, qb-inventory or your own through an open adapter.
- **Open where it matters.** Config, locales and bridges are never escrowed.
- **Tested before release.** Every resource boots on a real FXServer with each framework.
